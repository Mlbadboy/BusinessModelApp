## 3. The 13 Significance Sovereignty Laws (Invariant I21)

Batch 3.8.3 formally codifies and enforces **Invariant I21**:

> **Invariant I21 — Significance Sovereignty:**  
> **A radar signal is a candidate for attention. It is not an action, not a decision, not an emergency, and cannot manufacture execution authority.**

| Law Code | Law Title | Operational Contract Requirement | Status |
| :--- | :--- | :--- | :--- |
| **I21-A** | **Signal $\neq$ Action** | Detection cannot invoke tools, trigger external side effects, or reserve budget. | **ENFORCED** |
| **I21-B** | **Signal $\neq$ Decision** | A signal is input to decision intelligence, never a decision itself. | **ENFORCED** |
| **I21-C** | **Signal $\neq$ Emergency** | High severity/urgency cannot bypass approval gates or the Batch 6 execution firewall. | **ENFORCED** |
| **I21-D** | **Confidence Clamping** | $\text{Conf}_{\text{radar}} \le \min(\text{Conf}_{\text{causal}}, \text{Conf}_{\text{forecast}})$. Downstream confidence cannot exceed upstream evidence. | **ENFORCED** |
| **I21-E** | **Significance Threshold Gating** | Signals with confidence below `MinimumConfidenceThreshold` are clamped to `Informational` / `Unknown` tier. | **ENFORCED** |
| **I21-F** | **Deterministic Scoring** | Normalized weighted formula across Impact, Probability, Urgency, Persistence, Exposure, Confidence via versioned `RadarSignificancePolicy`. LLM never assigns ad-hoc priority. | **ENFORCED** |
| **I21-G** | **Constraint Pre-Flight Gating** | Signals exceeding resource/legal/brand constraints marked `Constrained` with safe alternatives (not discarded). | **ENFORCED** |
| **I21-H** | **Zero Execution Authority** | No execution permits, no task dispatches, no financial commitments emitted by radar subsystem. | **ENFORCED** |
| **I21-I** | **Provenance Linkage** | Every signal maintains immutable bidirectional linkage to source observation IDs, causal hypothesis IDs, and forecast IDs. | **ENFORCED** |
| **I21-J** | **Signal Lifecycle Determinism** | 8 formal states (`Detected`, `Active`, `Evaluating`, `Constrained`, `Mitigating`, `Exploiting`, `Dismissed`, `Expired`). | **ENFORCED** |
| **I21-K** | **Decay & Reinforcement** | Exponential temporal decay applies; corroborated signals receive deterministic reinforcement boosts. | **ENFORCED** |
| **I21-L** | **Epistemic Classification** | Every signal explicitly tagged `FactBacked`, `Inference`, `Hypothesis`, `ForecastDerived`, or `Unknown`. | **ENFORCED** |
| **I21-M** | **Cryptographic Auditability** | SHA-256 integrity hash across signal metadata, breakdown scores, and upstream lineage. | **ENFORCED** |
